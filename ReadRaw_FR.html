ReadRaw

À quoi ça sert

Lit vos fichiers Thermo .raw et écrit un petit rapport : échantillon, méthode, mode d'acquisition, résolution, gamme de masse… Sans ouvrir Xcalibur.

Installer (une seule fois)

  1. Installez Python. Pendant l'installation, cochez Add python.exe to PATH.
  2. Téléchargez ReadRaw. Clic droit sur le fichier .zip → Extraire tout, dans vos Documents.
  3. Ouvrez le dossier et double-cliquez sur install.bat. Si Windows affiche un avertissement : Informations complémentaires → Exécuter quand même.
  4. Attendez Setup complete, puis appuyez sur Entrée.

Ne déplacez plus le dossier ensuite (sinon, relancez install.bat).

Utiliser

  1. Sélectionnez un ou plusieurs fichiers .raw (ou un dossier).
  2. Clic droit → Afficher d'autres options → Extract RAW metadata.

Résultat, à côté de chaque fichier :

  • Echantillon.raw → Echantillon.md (le rapport, à ouvrir avec le Bloc-notes).
  • Plusieurs fichiers → en plus, raw_metadata.md : un tableau qui compare tous les fichiers.
